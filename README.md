# Dhuaan · धुआँ

**A weather forecast for smoke.** Live NASA satellite fire detections + wind forecasts → when farm-fire smoke will reach your area, how heavy, and where it's coming from — with alerts in Hindi and English before it arrives.

> धुआँ आने से पहले, ख़बर आपके फ़ोन पर।

Built for *Environmental Hacks* (WeMakeDevs × AWS, Bharat Builds Tour) — Track 01: Air.
